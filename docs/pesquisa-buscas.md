# Pesquisa: o que o marmorista procura no Google (23/11/2026)

Fontes: Google Trends Brasil (12 meses), autocompletar do Google (pt-BR, Brasil) e "As pessoas também perguntam".
O Trends não dá número exato de buscas; as comparações abaixo são relativas entre os termos.

## O que o Trends mostrou

- **"marmoraria"** tem busca firme o ano todo (cai só no fim de dezembro). Estados que mais buscam: ES, MG, SC, SP, PR.
  Quase tudo é busca local ("marmoraria perto de mim", "marmoraria + cidade"): é busca do **cliente final**, não do marmorista.
- Comparando assuntos técnicos (12 meses): **cuba esculpida** é o mais forte, com folga; depois **nicho de porcelanato/granito**,
  **soleira de granito**, **rodabanca**; "espessura granito" é baixo, mas constante.
- Frases "como fazer" (como polir / cortar / instalar granito, granito ou quartzo) têm pouco volume cada uma, mas são muitas e
  com pouca concorrência boa: valem como páginas de cauda longa.
- "marmorista" puxa: salário, o que faz, CBO, aposentadoria (curiosidade de quem pensa em entrar no ofício).
